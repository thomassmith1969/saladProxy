# Changelog

## v0.1.0 - 2026-05-23

- Initial public release of `salad_proxy`.
- Python package with module execution via `python -m salad_proxy`.
- Console entry points: `salad_proxy` and `salad-proxy`.
- Reverse proxy forwarding for GET, POST, PUT, PATCH, DELETE, OPTIONS, and HEAD.
- Explicit CONNECT rejection with HTTP 405.
- Streaming-friendly response passthrough for LLM chat endpoints.
- MIT license and public GitHub distribution instructions.
